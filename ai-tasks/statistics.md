# Описание задачи
Необходимо реализовать сбор статистики для пользователя (мерчанта) и для администратора

## Статистика для пользователя
Необходимо реализовать просмотр статистики по кассам:
Количество платежей по дням, месяцам, годам
Средний чек за день, год, месяц

## Статистика для администратора
Нужно сделать возможность получения статистики, какая касса/какой пользователь даёт какой доход 
нашей платёжной системы, по дням, месяцам, годам. Будем считать, что 10% всех успешных платежей - это наш доход.

## Желаемая реализация
Хочется, чтоб периоды в будущем можно было легко расширять. Думаю, уместно будет использовать 
паттер Стратегия.

Нужно заполнить пустые периоды (дни, месяца, года без платежей). Давай, чтоб не усложнять SQL,
сделаем дозаполнение пустых периодов на стороне PHP.
