# Описание проекта Training Payment System

Проект представляет собой учебную платёжную систему, сделанную на PHP (фреймворк Laravel). 
Вместо использования внешних сервисов для реального приёма денег, используются форма с двумя
кнопками: успех, провал.

Денежные единицы храним как целые, в тийинах (валюта предполагается UZS).

## Архитектура проекта
Проект использует базовую структуру Laravel-приложения, при этом код из контроллеров выносится в сервисы.
Слоя "Репозиторий" не существует, сервисы напрямую вызывают Eloquent.

## Тестирование проекта
Проект пишется по методологии TDD, тестируется, в основном, Feature-тестами. Unit-тесты используются для
тестирования кода, который может быть исполнен в изоляции от остальной системы, включая фреймворк.
Например, проверка подписи.

Часть тестов на проекте написана вручную, и не полные, для экономии времени. Но ты пиши при генерации 
полные тесты. 

## Запуск php
Запуски PHP следует осуществлять на основе докер-контейнера для разработки, находящегося в корне проекта,
в папке docker, через docker compose, контейнер php. Например,
```
docker compose exec -u www-data php php artisan route:list
```
